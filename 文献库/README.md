谱簇论文直接相关的39份 PDF：34份 Bloch/本征子空间/2026邻近工作，以及5份可信评估

5. `00_当前主线必读/06_FalsifyPDE_基准与可信评估/`：弱基线、PINN/FEM 与可信评估。

## 引用边界

- 文件名带 `preprint` 通常指本地作者版，不等于论文未正式发表；
- workshop、arXiv 和正式期刊必须在正文中明确区分；
- 投稿参考文献统一见代码仓库 `paper/p2_final/MANUSCRIPT.en.md` 与
  `CITATION_AUDIT.zh-CN.md`；
- 不再使用已删除的 `Final_Complete_Library.bib`，因为其元数据没有完成投稿级核验。
