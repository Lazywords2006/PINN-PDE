## 建议补（冲击 SCI 三区）

1. 增加第三势族或不同晶格，只作为可选泛化，不回头修改 frozen-final 或 supplement；
2. 补 GPU-PWE 或统一设备的速度敏感性，降低“GPU 对 CPU 不公平”的质疑；
3. 报告 external gap 与 projector error 的分层曲线；
4. 如目标期刊强制报告 FLOPs，补固定 CUDA profiler 计数。

## 不建议补

- 不再增加 P5 low-ROM 或 P1 routing 的训练规模；两条路线已经按冻结门槛 STOP；
- 不用 10 seeds 重跑现有 final；3 seeds 与点聚类 bootstrap 已形成主统计证据；
- 不用多卡、H100 或超大模型；当前方法只有约 9.2k 个可训练参数；
- 不把普通 residual PINN + 更多层数当作主要创新；该比较可以做基线，不能替代最近邻对照；
- 不在 final 上选择第三势族、壳层数或误差门槛。

## 算力估计

- 当前论文整理、画图、理论和引用：本地 Mac/CPU，0 张 GPU；
- 最近邻 supplement 已使用单张 RTX 5090 D 完成，远端已关机；
- 加第三势族与同设备效率复核：再预留 6–12 小时；
- 不需要多卡。

## 成功线

已完成 supplement 回答了前两个核心问题：

1. P2 在新参数集上稳定优于较强的 Wang–Xie trace 适配；
2. P2 在两个势族、五个 split 和6/6 family×seed上保持优势；
3. P2 的精度优于同延迟量级 Dai 适配，但显著慢于轻量 trace 基线。

当前最重要的剩余成功线是：论文主张必须匹配现有理论和实验，不能把适配结果写成作者
官方实现，也不能用 Dai 适配的失败夸大普适优势。
