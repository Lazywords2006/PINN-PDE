## 二、当前主线：Wentzell / PINN（暂停中）

对象：单位圆盘 u_t−Δu=0，圆周动态边界 c u_Γ,t − d Δ_Γ u_Γ + ∂_ν u + κ u_Γ = 0。c∈[.01,10]、d∈[.01,1] 为对数分布，κ 取 0 或 [.1,1]，输出时刻 .05、.1、.25、.5、1。原资格：体/面 relative L2 ≤1e-3，真法向/切向误差 ≤1e-2，归一化质量/储能缺陷 ≤1e-4。门槛没有放宽。

| 方面 | 结果 |
|---|---|
| 强经典基准 | A86 六个经典控制验证集 16/16、新开发集 8/8；最强 CachedPhysicalN8 平均 1.31 ms/query |
| 神经方法 | A86 六个神经模型（24 次更新、864 个输出）验证集每个 0/16、新开发集每个 0/8；每 query 95.9–110.8 ms；最大体误差约 0.93。仍无神经方法过原资格 |
| 硬动态边界构造 | 动态 Γ 条件代数满足（true Γ 残差约 8.36e-13），但不保证内部 PDE、通量、质量、储能。与 Hermite/TFC、Robin 构造直接对应，不能称新的通用硬约束框架；Wentzell 专门化尚未证明独立新颖 |
| 初始角点限制 | 固定参数、有限权重下，某些仿射初值响应的体残差边界迹在 t→0 趋于 3β（手工推导，不是误差下界）。A60 的 heat-Hermite 分支已测试，不支持生产 |
| 锚定残差、预算投影 | A84 打开 trunk 梯度通道（占比 23.3%–45.0%）；A85 的有限预算投影局部成立；都没有转成整体精度 |
| B 路 分段随机特征 | 三种子各 100/100 过原资格；是逐 query 最小二乘，不是免费神经推理；旧配对经典数组缺失，不能补成严格胜负 |
| C 路 读出优化 | 读出实现等价（最大差约 5.98e-12），精度未修复，神经 0/2 |
| 费用 | A 已知下界 3996.57 s、B 242.88 s、C 2372.14 s（不同 host 且并行，不可相加）；完整 Q100、金额、历史失败与选择费用仍为 null |

结论：目前没有证据表明神经方法在原资格与完整费用上胜过最强经典方法，也没有成熟的新方法论文。已有素材是强经典基准、已验证的硬 Γ 构造、角点相容性分析和一组排除无效方向的记录。

近邻文献：2026 年一维 Wentzell PINN 基准（oms2026.0303）、2025 年带动态边界的 Allen–Cahn PINN（arXiv 2507.09757）。“首次把神经方法用于 Wentzell”的说法站不住。

**训练量事实（2026-10-15 复核累计记录）**：旧 A 路每个神经模型记录在案的优化步数只有 4–64 次 Adam 更新（A86 每模型 4 次、A54 16 次、A26 64 次；A39 另有少量 L-BFGS），C17 为 300 次 Adam 加 90 次 L-BFGS 外层；合同另设每模型 120 s 墙钟上限。常规 PINN 通常需要 10⁴–10⁵ 步。未逐条核实这些更新是否接在更早的预训练权重之后，但“神经 0/16”很大程度上可能是训练量不足，而不是方法本身做不到。

### R32 诊断阶梯（进行中，2026-10-15 起）

本地、单角模、固定参数的 vanilla PINN 基线，逐个拆开旧合同叠加的难度因素，找第一个失效台阶。协议、仪器验证与结果在 `自主研究/当前主线/round32_pinn_diagnostic_ladder/`（[PROTOCOL](../自主研究/当前主线/round32_pinn_diagnostic_ladder/PROTOCOL.md)、[VALIDATION](../自主研究/当前主线/round32_pinn_diagnostic_ladder/VALIDATION.md)）。参考解两种独立方法最大差 4.4e-10；118 项测试通过。vanilla 配置每个 run 2 万步 Adam 加至多 3000 次 L-BFGS。台阶：R0（m=0）、R1（m=1、2）、RC（兼容初值，修订 1）、R2–R4（c、d、κ 单轴）、R5（八角）。旧资格合同不动。

第一阶段（R0、R1、RC，33 个 run，2026-10-16，[报告](../自主研究/当前主线/round32_pinn_diagnostic_ladder/STAGE1_REPORT.md)）：

- **首个失效台阶 = R0**：`m0_lin`@P0 三个种子体误差 1.1e-2–2.9e-2，均未达 U 级 1e-2；R1 的 `m1_lin` 也失败。
- **初-边界不相容是主因（观察）**：换成相容本征函数初值后，m=0、1 误差降到约 1e-4，多数达 C 级；不相容格点误差随错配大小增长（五格点 log-log 相关 0.995）；误差从 t→0 的边界角点开始。
- **第二个因素是时间衰减跨度**：m=2 的解到 t=1 衰减到 0.5%，相对误差在晚期被放大。
- 近邻检查（[NOVELTY_CHECK](../自主研究/当前主线/round32_pinn_diagnostic_ladder/NOVELTY_CHECK.md)）：初始层校正的设计模式已有定常先例，针对初-边不相容的时间角点层未检出先例；e^{−λt} 缩放是 Zong 2023 的特例，只作消融。

第二阶段（第 8 节探针 36 个 run、修订 2/2b 对照 48 个 run，2026-10-16/17 主要在云端完成，[报告](../自主研究/当前主线/round32_pinn_diagnostic_ladder/STAGE2_REPORT.md)）：

- **第 8 节**：宽度 32/128、lr₀ 3e-3、Adam 5k/60k、关 L-BFGS、Nf=16384 共 7 种单项改动，都没有让 m0_lin@P0 达到 U 级（每种 ≤1/3）。按协议不能写“失败来自配置/预算”；结论只覆盖已测改动，不等于证明了结构性失败。Adam 加到 6 万步，中位数只从 2.0e-2 降到 1.4e-2。120 s 量级预算（按步数）下约 9.6e-2。探索性权重探针中只有 w_ic=10 以 2/3 勉强达到 U 级。
- **layer（初始层提升）达到修订 2b 判据**：m0_lin、m1_lin 的体误差中位数分别降到 6.1e-4、1.1e-3（比冻结 vanilla 低 33、27 倍），低于 w_ic=10、硬初值、t≈0 加密采样三个基线（对硬初值低 3.6、5.0 倍），两格 3/3 达 U 级。但没有 run 达 C 级，法向通量误差未改善。
- **decay 未达修订 2 判据**：m2_eig1 降 60 倍，m2_const 反而差 1.6 倍。layer+decay（未预注册判据）是 m2_const 上唯一明显改善的方法（低 3 倍）。
- 诊断：layer 让误差不再从边界角点开始增长；硬初值把冲突推到边界项（边界残差 6.6e-2），所以在种子之间不稳定。
- 只覆盖 P0 一个参数点；R2–R5 未跑；离旧资格合同仍远。

## 六、待用户确认的论文路径（2026-10-15 对话，尚未采纳）

网络固定为 PINN 时，论文主张不应是“比经典快”，而应是诊断并修复 PINN 的某个具体失败。下面三个候选主张按“已有素材 / 风险”列出，选哪个由用户定。

1. **动态边界硬约束的初始角点相容性障碍与相容提升**：已有 t→0 的 3β 推导和 A60 负结果；风险是目前还没有一个有效的修复。
2. **由稳定性估计导出的损失范数与权重**：通量、质量、储能误差在 L² 残差下失控是现有 A86 数据的共同特征；需要先推导并查近邻。
3. **强基线诊断与负结果基准**：材料最全、风险最低，影响力也最低。

推进顺序：先建诊断阶梯（单角模、固定参数 → 逐轴放开 c、d、κ），找到 vanilla PINN 第一个失效台阶，再从该失败出发选改进方法，并对 vanilla PINN 与已有 PINN 变体做消融。论文用的指标另立，不改旧资格合同。
