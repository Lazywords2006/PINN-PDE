# R32 第二阶段结果：第 8 节探针与修订 2/2b 对照（2026-10-17）

范围：只有参数点 P0 = (c=0.3, d=0.1, κ=0.3)，单角模。R2–R5 本轮未跑。冻结配置、判据和修订 1、2、2b 均未改动，没有追加调参。

运行环境：第 8 节探针中 9 个 seed 0 的 run 在本机完成（2026-10-15/16），其余 27 个探针和全部 48 个对照 run 在云端容器完成（2026-10-16/17，4 核，P=4，每 run 单线程）。软件版本两边相同：torch 2.14.1、float64。不同的是 numpy（本机 2.4.6，云端 2.5.3）和 scipy（本机 1.17.1，云端 1.18.1）。冻结 vanilla 基线（`runs/cells/`）是第一阶段在本机跑的。精度可以跨主机比较；**墙钟不跨主机比较**，下文的墙钟只在云端 run 之间对比。云端容器在 10-17 约 02:00 JST 重启过一次，正在训练的 4 个 run 丢失、按原种子重跑，已完成的 run 不受影响。

原始记录：`runs/probe_*/`、`runs/var_*/`、`runs/base_tpow2/`。表格分别由 `run_probes.sh`（输出 `runs/probes_report.txt`）、`ladder.py report` 和 `compare_summary.py`（输出 `runs/compare_summary.md`）生成。

## 结论

1. **第 8 节：7 种超参/训练量改动都没有让 m0_lin@P0 达到 U 级**（每种改动 3 个种子中达标数 ≤1）。按协议，失败不能写成“来自配置/预算”。这个结论只覆盖已测的这 7 种单项改动，不等于证明了“结构性失败”。
2. **训练量不是主因**：Adam 从 2 万步加到 6 万步，体误差中位数只从 2.0e-2 降到 1.4e-2；Nf 加到 4 倍、宽度加到 2 倍都没有改善。L-BFGS 必不可少，关掉后误差升到 8.1e-2。按步数定义的 120 s 预算下误差 9.6e-2，比 U 级门槛高约 10 倍。
3. **损失权重探针（探索性）**：只有 w_ic=10 让格点达到 U 级（2/3），而且贴着门槛（6.5e-3、1.3e-2、4.2e-3），预算缺陷也变大了。w_ic=100 和 w_bc 两档都没通过。
4. **修订 2b 的 layer 判据：满足（有效）**。m0_lin 和 m1_lin 上体误差中位数分别比冻结 vanilla 低 33 倍和 27 倍，都低于三个基线，两个格点都是 3/3 达 U 级。
5. **修订 2 的 decay 判据：不满足（部分有效）**。m2_eig1 上低 60 倍，但 m2_const 上反而高 1.6 倍。
6. layer 没有让任何 run 达到 C 级。layer 的法向通量误差也没有改善：m1_lin 上中位数 3.7e-2，冻结 vanilla 为 4.7e-2。layer 解决的是体和迹误差，还没有解决通量误差。

观察：

- **种子间差异接近门槛附近的差距**。seed 2 在多数探针里明显更容易达标，冻结 vanilla 本身也是 seed 2 最好（1.1e-2）。宽度 128、lr₀ 3e-3、w_bc 0.1 的唯一一个达标 run 都是 seed 2。因此“1/3 达标”不应解读成“接近通过”。
- 能让误差稳定下降的单项改动只有两类：加 Adam 步数（下降约 1.4 倍）和加大初值项权重（下降约 3 倍）。后者直接作用在初值和动态边界冲突的那一项上，与第一阶段“初始层是主因”的观察一致。
- w_ic 加大时能量缺陷变大（w_ic=10 中位数 3.6e-3，冻结 vanilla 1.0e-3）。加权只是把冲突从初值项挪到了别处，没有消除冲突。

## 三、逐项对照预注册判据

**layer（修订 2b，约束判据）：有效。**

| 条件 | m0_lin | m1_lin |
|---|---|---|
| 比冻结 vanilla 低 ≥3 倍 | 32.9 倍 ✓ | 27.0 倍 ✓ |
| 低于 w_ic=10 | 6.1e-4 < 6.5e-3 ✓ | 1.1e-3 < 1.0e-2 ✓ |
| 低于 hardic | 6.1e-4 < 2.2e-3 ✓（3.6 倍） | 1.1e-3 < 5.3e-3 ✓（5.0 倍） |
| 低于 t_power=2 | 6.1e-4 < 4.4e-2 ✓ | 1.1e-3 < 6.4e-2 ✓ |
| 格点 U 级（≥2/3） | 3/3 ✓ | 3/3 ✓ |

对 hardic 的优势是三个基线里最小的（3.6 倍和 5.0 倍），而且 hardic 的 seed 0 在 m0_lin 上（2.6e-4）比 layer 的两个种子还好。layer 赢在稳定：hardic 每个格点都有一个种子失败（1.4e-2、2.9e-2），layer 9 个相关 run 都达到 U 级。只有 3 个种子，中位数的差别不应过度解读。

**decay（修订 2）：部分有效，判据不满足。** m2_eig1 上低 59.9 倍（满足），m2_const 上是 0.61 倍，即反而更差（不满足）。decay 单独用只在相容初值上有效。初值不相容时，角点层仍然主导误差，单纯的时间缩放无济于事。

**layer+decay（未预注册判据，只作报告）**：m0_lin、m1_lin 上也比 vanilla 低 ≥3 倍、低于全部基线，且达到 U 级，但中位数不如单独的 layer。它是 m2_const 上唯一明显改善的方法（2.7e-3，低 3.0 倍，3/3 达 U 级），通量误差也最低。也就是说，两个因素同时存在时，两个改动需要一起用。这是事后观察，不构成判据结论。

**其它基线**：t_power=2（在 t≈0 附近加密采样）在两个主要格点上都比冻结 vanilla 差约 2 倍，加密采样无助于角点层。

## 四、诊断（`diagnose.py`，只观察，不重训）

已生成：`runs/var_layer/` 中 m0_lin、m1_lin 的 seed 0，`runs/var_hardic/` 中 m0_lin 的 seed 2，`runs/var_layer+decay/` 中 m2_const 的 seed 0（`*_diag.png/json`），与第一阶段的 vanilla 诊断对照。

- **冻结 vanilla**（m0_lin、m1_lin，seed 0）：t ≤ 0.17 时，最大误差都位于边界 r=1；体误差从 t=0.002 的 7e-3（m1_lin 为 1.5e-2）单调增长到 2–3e-2。训练末初值项损失最大。
- **layer**（m0_lin、m1_lin，seed 0）：体误差在全时段都在 3e-4 到 1.3e-3 之间，没有随时间增长。最大误差的位置不再固定在边界，在原点、内部和边界之间变化。训练末初值项损失从 1e-4 降到约 1e-5，剩余损失主要是 PDE 残差（1e-4 到 3e-4）。也就是说，校正项吸收了角点冲突，剩下的是普通的拟合误差。
- **hardic 失败种子**（m0_lin，seed 2）：初值精确满足，但边界残差 RMS 是 6.6e-2（layer 为 1.3e-3），误差仍从边界开始增长到 1.4e-2。硬初值把冲突从初值项推到了边界项，没有消除冲突。这解释了 hardic 为什么在种子之间不稳定。
- **layer+decay**（m2_const，seed 0）：误差约 2e-3，全时段平稳，最大误差仍在边界，剩余误差主要来自 PDE 残差（7.6e-4）。

## 五、解释边界

- 只有一个参数点 P0。角点层的时空尺度依赖 c（半直线模型中 c 进入边界阻抗），c 取两端时校正项的作用可能不同；本轮没有任何证据能外推到参数区间。
- layer 用到了初值多项式和参数的解析信息（δ 和 c），不是一个与问题无关的通用技巧。τ=0.1 是预设的，没有调过。
- layer 未达到 C 级，法向通量误差没有改善。离旧资格合同（体 ≤1e-3、通量 ≤1e-2、预算缺陷 ≤1e-4，覆盖全参数区间）仍然很远。本轮的任何数字都不构成旧合同下的资格结果。
- 近邻检查（[NOVELTY_CHECK.md](NOVELTY_CHECK.md)）：针对初-边值不相容的时间角点层未检出先例；设计模式（奇异/边界层提升）在定常问题上已有先例。decay 是 Zong 等 2023 时间包络归一化的特例，只作消融。
- 墙钟：云端条件下 layer 的墙钟中位数比 hardic、t_power=2 高约 10%（约 3700 s 对 3400 s，同主机同负载）。
