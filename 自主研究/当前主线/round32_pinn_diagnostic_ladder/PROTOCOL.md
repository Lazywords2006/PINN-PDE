## 1. 问题

单位圆盘，bulk 扩散系数 1，零强迫，外法向 ν：

- 体：u_t = Δu
- 边界（Wentzell）：c u_Γ,t − d Δ_Γ u_Γ + ∂_ν u + κ u_Γ = 0
- T = 1，输出时刻 t ∈ {0.05, 0.1, 0.25, 0.5, 1}

单角模约化：u = r^m F(s,t) cos(mθ)，s = r²。则

- 体：F_t = 4 s F_ss + 4(m+1) F_s
- 边界 s=1：c F_t + (d m² + κ + m) F + 2 F_s = 0
- 初值 F(s,0) = f(s)

这与旧云端 A 路的“单响应”表示一致（P_m·F）。约化保证原点正则，不属于本阶梯要考察的因素。

能量恒等式（用于参考解自检）：E = ½[∫₀¹ F̃² r dr + c F̃(1)²]，F̃ = r^m F(r²)，dE/dt = −[∫₀¹ (F̃_r² + m² F̃²/r²) r dr + (d m² + κ) F̃(1)²]。κ=0 且 m=0 时 ∫F̃ r dr + c F̃(1) 守恒。

## 2. 五个响应（取自旧资格合同的响应族）

| 名称 | m | f(s) |
|---|---|---|
| m0_const | 0 | 1 |
| m0_lin | 0 | s − 1/2 |
| m1_const | 1 | 1 |
| m1_lin | 1 | s − 3/5 |
| m2_const | 2 | 1 |

κ=0 时 m0_const 是精确稳态，只作平凡门，不计入阶梯。d 对 m=0 无作用，m=0 响应不参与 d 轴。

## 3. 参考解

主参考：Bessel 本征展开，特征方程 (d m² + κ − c μ²) J_m(μ) + μ J_m′(μ) = 0，权内积 ⟨f,g⟩ = ∫₀¹ f g r dr + c f(1) g(1)。
独立核对：s∈[0,1] 上的 Chebyshev 配置法，边界节点按 F_t = −(bF + 2F_s)/c 演化，用矩阵指数积分。
两者在全部阶梯参数点上的差须 ≤ 1e-9 才可使用。

## 4. Vanilla PINN（冻结配置）

- 网络：tanh MLP，输入 (s,t)，4 个隐层 × 64，输出 F，Xavier 初始化；float64，CPU 单线程
- 损失：L = mean R_pde² + mean R_bc² + mean (F−f)²，三项权重均为 1，全部软约束
- R_pde = F_t − 4 s F_ss − 4(m+1) F_s；R_bc = c F_t + b F + 2 F_s（s=1）
- Adam 阶段：20000 步，lr 1e-3 指数衰减到 1e-5；每步重采样 Nf=4096（s,t 均匀），Nb=256（t 均匀，s=1），N0=256（s 均匀，t=0）
- L-BFGS 阶段：strong-Wolfe，history 50，最多 3000 次迭代；固定点集 Nf=8192、Nb=512、N0=512
- 种子 0、1、2；训练墙钟只记录，不设上限（旧合同对每个训练模型有 120 s 上限，这一点单独作为探针，见第 8 节）

## 5. 评价（独立评价器，对参考解计算）

对每个输出时刻：

- 体相对 L²：√(∫(F̃−F̃_ref)² r dr / ∫F̃_ref² r dr)
- 迹相对误差：|F(1,t)−F_ref(1,t)| / |F_ref(1,t)|
- 法向通量相对误差：(mF+2F_s)|_{s=1} 对参考解的相对误差
- 能量预算缺陷 |E(t)−E(0)+∫₀ᵗD| / E(0)，以及 m=0 时质量预算缺陷（NN 自洽量，同时对参考解算一遍作为求积底噪）。**这是阶梯自定义的口径，与旧合同“归一化缺陷”的冻结口径可能不同。**
- 切向梯度相对误差对单角模等于迹相对误差，不另列。

## 6. 通过判据

- **U 级（可用）**：一个 run 在全部 5 个时刻体 L² 与迹误差 ≤ 1e-2，法向通量相对误差 ≤ 1e-1。
- **C 级（合同量级）**：体、迹 ≤ 1e-3，法向通量 ≤ 1e-2，两个预算缺陷 ≤ 1e-4。C 级只作报告，不用来定义“首个失效台阶”，也不构成旧合同资格。
- **格点（cell）** = 台阶 × 参数点 × 响应。格点 U 级通过当且仅当 3 个种子中至少 2 个 run 达到 U 级。
- **首个失效台阶**：下列台阶顺序中，第一个含有 U 级未通过格点的台阶。

## 7. 台阶

参数中心 P0 = (c=0.3, d=0.1, κ=0.3)（c、d 区间的几何中点附近，κ 取 [0.1,1] 内部）。

| 台阶 | 内容 |
|---|---|
| R0 | m=0：m0_lin（以及 κ>0 时的 m0_const）于 P0 |
| R1 | m=1、2：m1_const、m1_lin、m2_const 于 P0 |
| R2 | c 轴：c ∈ {0.01, 0.03, 0.1, 0.3, 1, 3, 10}，其余取 P0，全部 5 个响应 |
| R3 | d 轴：d ∈ {0.01, 0.03, 0.1, 0.3, 1}，其余取 P0，仅 m≥1 的 3 个响应 |
| R4 | κ 轴：κ ∈ {0, 0.1, 0.3, 1}，其余取 P0，全部响应（κ=0 时排除 m0_const） |
| R5 | 区间八角：c∈{0.01,10}、d∈{0.01,1}、κ∈{0.1,1}，响应 m1_lin、m2_const |
| R6 | 参数化单网络（输入 c,d,κ）——本阶段不跑 |

执行规则：R0、R1 先跑。若 R0 或 R1 出现 U 级失败，该台阶即为首个失效台阶；R2–R4 仍各自完整跑完以定位参数区，但首个失效台阶不变。不为救通过而调超参；冻结配置之外的改动只出现在第 8 节探针中。

方法（网络、优化器、点数、步数完全沿用第 4 节冻结配置，不另调参）：

- **layer（初始层提升）**：F = N + δ·w((1−s)/2, t; c)·e^{−t/τ}。δ 为 t=0、s=1 处动态边界与体方程各自要求的 F_t 之差，由初值多项式和参数解析算出，不用参考解。w 为半直线模型 w_t = w_xx、c w_t − w_x = c（x=0）、w(x,0)=0 的闭式解（erfc/erfcx 表达）。τ 固定为 0.1，不调。
- **decay（衰减缩放）**：F = e^{−λt}·N，体与边界残差乘 e^{λt}（即 N 方程的残差）。λ 取该格点最慢本征值（由 Bessel 特征方程求根得到的一个标量）。
