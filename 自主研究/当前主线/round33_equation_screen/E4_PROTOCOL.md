# R33-E4：体–面耦合反应扩散的预注册协议（草案，2026-10-20 JST）

状态：**协议、参考解、PINN 实现和测试已完成（`test_screen.py` 共 39 项通过，其中 E4 新增 11 项）；尚未跑任何 PINN 筛选，没有任何 PINN 结果。** 看到任何 E4 的 PINN 结果之前，本文只能追加“修订记录”。

## 1. 为什么加 E4

E1–E3 的错配都是同一种：边界要求的 u_t 与体方程要求的 u_t 不同（u 本身在角点连续，u_t 跳变）。E4 的错配是另一种：**通量跳变**，u 在角点连续，但 u_x 跳变，解在 t→0 有 √t 型奇异。如果解析校正在 E4 上同样有效，说明方法不依赖“u_t 跳变”这一种机制；如果无效，如实写成局限。

## 2. 方程（一维，x∈[0,1]，T=1）

体：u_t = D u_xx + u(1−u)，D=0.1；x=0：u_x=0。
x=1：通量交换 D u_x = κ (v − u)，κ=1。
表面变量 v(t)（独立未知量）：v_t = κ (u(1,t) − v) − γ v³，γ=1。
初值：u(x,0)=f(x)=0.1(1−x²)，v(0)=V0=1。

通量错配（以 y=1−x 为坐标，D u_y 的跳变）：Δ_y = κ(f(1)−V0) + D f′(1) = −1 + 0.1·(−0.2) = **−1.02**。（E3 的 δ 是 +3.42，量纲不同，不能直接比大小。）

## 3. 解析校正（通量层）

半直线 y≥0 上，U_t = D U_yy，D U_y(0,t)=Δ_y（常数通量），U(y,0)=0 的解为
U(y,t) = −2 Δ_y √(t/D) · ierfc( y / (2√(D t)) )，ierfc(z)=e^{−z²}/√π − z erfc(z)。
它给出 u(1,t) − f(1) ≈ −2Δ_y √(t/(πD))（t→0）。

模型：u = f + t·N_u + U(y,t)·e^{−t/τ}，τ=0.1（沿用 R32，不调）；v = V0 + t·N_v(t)。t=0 时 U=0，初值仍精确满足。注意这只是**首阶**校正：它假定通量常数，未含 v 与 u 的耦合反馈，由网络学余项。

**已做的核对（原型 `e4_reference_prototype.py`）**
- 参考解：Chebyshev 配置 + Radau（rtol 1e-12），边界节点通量条件做代数消去，表面变量 v 加入 ODE。N=48 与 96 在输出时刻 t∈{0.05,0.1,0.25,0.5,1} 的最大差 ≤ 2.5e-12（t=1e-3 为 1.3e-6，t=1e-4 为 4.6e-5，早期层未被充分分辨，但**输出时刻不含这些**）。
- √t 系数：参考解 (u(1,t)−f(1))/√t 在 t=1e-4 为 3.54，校正预测 3.64（相差 2.8%，随 t→0 趋近，t=1e-3 为 3.34）。符号和量级正确。
- **未做**：独立的第二参考（E1 当时用了本征展开）；E4 非线性，没有闭式，可退而用 N=96 对 N=192 的自检加 Radau 与另一积分器（如 LSODA/BDF）的互校。写 PINN 代码前补。

## 4. 方法与预算（与 §3、修订 1 相同，网络加一个表面分支）

- u 分支：tanh MLP 4×64，Xavier，float64，输入 (x,t)；v 分支：tanh MLP 3×32，输入 t。
- 方法：vanilla（u=N_u，v=N_v，全部软约束）、hardic（u=f+tN_u，v=V0+tN_v）、rba（逐点残差注意力，同 R33）、hardic+layer（本文）。不再跑单独的 layer。
- 损失（权重均 1）：体残差、x=0 的 u_x、x=1 的通量残差 D u_x − κ(v−u)、表面 ODE 残差、u 初值（vanilla）、v 初值（vanilla）。
- 筛选预算：Adam 4000，L-BFGS 500，Nf=2048、Nb=128、N0=256，种子 0、1。确认预算：同修订 1（Adam 20000、L-BFGS 3000、Nf 4096/8192），种子 0、1、2。
- 指标：体相对 L²（上述 5 个输出时刻取最大），另报 v(t) 的最大绝对误差。

## 5. 判据（先筛选，通过再确认）

筛选通过需同时满足：(a) 参考解自检 ≤1e-8；(b) vanilla 主指标 >1e-2；(c) hardic+layer 主指标比 hardic 与 rba 中较好者低 ≥3 倍。
确认阶段：同修订 1 的判据（E4 的 hardic+layer 中位数比 hardic、rba 中较好者低 ≥3 倍，且 ≥2/3 个种子体误差 ≤1e-2）。

**预注册预测**：通量层的奇异比 E1–E3 的 u_t 跳变层弱（u 连续，只有 √t），所以优势会小于 E1，但此处 |Δ_y| 很大（1.02 且 V0 远离 f(1)），预测筛选时 hardic+layer 仍优于 hardic，倍数在 2–10 之间；若 <2 或 >10 如实记为预测落空。

## 6. 不做的事

不调 τ、网络、预算迁就某方法；不因结果不好改方程；不把 E4 的结果并入 E1–E3 的结论，单独报告。E5（Cahn–Hilliard 动态边界）是四阶方程，参考解和损失都要重做，本轮不做，等 E4 出结果再定。

## 观察（事后，不改变判定）

1. **E4 上最好的是 vanilla**，比所有硬初值方法都低（2.3e-2 对 6.9e-2~9.6e-2），也比 hardic+layer 好约 3 倍。这与 E1–E3 完全相反：那里硬初值系列整体好于 vanilla。
2. 误差集中在早期时刻：t=0.05 时 vanilla 1.9e-2，hardic+layer 6.8e-2。层校正没有压低早期误差，与它在 E1–E3 上的作用相反。
3. 同一种子内 hardic 波动大（4.7e-2 与 1.5e-1），hardic+layer 稳定（6.8e-2 与 7.1e-2）：层校正减小了方差，但没有降低水平。
4. 可能原因（**都是未检验的假设，不是结论**）：(i) 本方程的校正只是首阶项（常通量、不含 v 与 u 的反馈），在 t=0.05 时 u(1,t) 已移动约 0.46，剩余部分很大，网络仍要学；(ii) 硬初值因子 t 使网络在 t→0 附近难以补偿一个 √t 型的余项；(iii) 小预算（4000 步）下的优化问题。要区分这些需要额外实验（完整预算、改 τ、二阶校正），**不在本协议内，也不会为救判据而加**。
5. 与 E1–E3 的对比说明：“解析角点层校正有效”目前只对 u_t 跳变型的错配成立；对通量跳变型（E4）在筛选预算下无效。这是一个需要写进论文局限的结果。
