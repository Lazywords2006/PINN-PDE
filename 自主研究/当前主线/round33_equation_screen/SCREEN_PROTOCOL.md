## 1. 要检验的主张（筛选级，不是论文证据）

“相容性感知的硬约束”：在近两年常用的硬初值 u = f + t·N 上，再加一个解析的时间角点层校正项。在初值与动态边界不相容的方程上，它的误差比硬初值和残差注意力（RBA）低。

## 2. 方程（一维，x ∈ [0,1]，T = 1）

统一形式：体方程 u_t = D u_xx + R(u)；x = 0 处 u_x = 0；x = 1 处动态边界 c u_t + D u_x + G(u) = 0；初值 u(x,0) = f(x)。

| 编号 | 名称 | D | R(u) | G(u) | c | f(x) |
|---|---|---|---|---|---|---|
| E1 | 线性热方程 + Wentzell 型动态边界 | 1 | 0 | 0.3 u | 0.3 | x² − 1/2 |
| E2 | Allen–Cahn + 动态边界 | 0.01 | u − u³ | 1.0 u | 0.3 | 0.5 cos(πx) |
| E3 | Fisher–KPP + 储库型动态边界 | 0.1 | u(1 − u) | 1.0 (u − 1) | 0.3 | 0.1 (1 − x²) |

三个方程在 x = 0 处都与初值相容（f′(0) = 0）；在 x = 1、t = 0 处，体方程和动态边界要求的 u_t 不同（不相容）。错配 δ = u_t(边界) − u_t(体)，由 f 和参数解析算出。

参考解：在 x 上用 Chebyshev 配置法加线方法，用 scipy Radau 积分（rtol 1e-12）。x = 1 的边界节点按动态边界作为 ODE 演化，x = 0 的节点用 Neumann 条件消去。用两种分辨率（N = 48 与 N = 96）在全部输出时刻上的最大差来自检，须 ≤ 1e-8 才可使用。

## 3. 方法（网络和优化器完全相同）

公共配置：tanh MLP，输入 (x, t)，4 × 64，Xavier 初始化，float64，单线程。Adam 4000 步，lr 1e-3 指数衰减到 1e-5，每步重采样 Nf = 2048、每个边界 Nb = 128、N0 = 256；然后 L-BFGS 最多 500 次迭代，固定点集 Nf = 4096、Nb = 256、N0 = 512。损失为体、x=0 边界、x=1 边界、初值四项的均方，权重均为 1（硬初值时没有初值项）。种子 0、1。

| 方法 | 构造 | 来源 |
|---|---|---|
| vanilla | u = N，全部软约束 | 基线 |
| hardic | u = f + t·N | 近年常用的硬初值（SPINN 2025 等） |
| rba | u = N，残差注意力逐点权重：λᵢ ← 0.999 λᵢ + 0.01 |rᵢ|/max|r|，Adam 阶段用固定点集，L-BFGS 阶段权重冻结 | Anagnostopoulos 等 2024 |
| layer | u = N + δ·w(y, t; c′)·e^{−t/τ} | R32 修订 2 的初始层提升 |
| hardic+layer | u = f + t·N + δ·w(y, t; c′)·e^{−t/τ} | 本轮的候选方法 |

其中 y = (1 − x)/√D，c′ = c/√D，w 为 R32 的半直线单位错配解（c′ w_t − w_y = c′，y = 0；w(y,0) = 0），τ = 0.1，与 R32 相同，不调。t = 0 时 w = 0，所以 hardic+layer 仍精确满足初值。

## 4. 评价

输出时刻 t ∈ {0.05, 0.1, 0.25, 0.5, 1}。指标为体相对 L²（x 上 Gauss–Legendre 求积）和 x = 1 处迹的相对误差，取全部时刻的最大值。主指标：2 个种子的最大体相对 L² 的中位数（2 个种子时即平均值）。

## 5. 入选判据（每个方程单独判）

一个方程入选论文候选，需同时满足：

1. 参考解自检 ≤ 1e-8。
2. vanilla 明显失败：主指标 > 1e-2。
3. layer 与 hardic+layer 中较好的一个，主指标比 hardic 和 rba 中较好的一个低至少 3 倍。

只有 2 个种子、小预算，结论只用来决定下一步投入哪个方程，不作为论文证据。达不到判据如实写，不为救判据追加调参。

## 6. 不做的事

- 不调 τ、网络规模或预算来迁就某个方法。
- 不在筛选结果上宣称新颖性或优势。
- E4（体–面耦合反应扩散）、E5（Cahn–Hilliard 动态边界）等前三个方程出结果后再决定是否加入，加入时以修订预注册。
